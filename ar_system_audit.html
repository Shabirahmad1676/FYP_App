Crash Risk ARScene rendered before ViroARTrackingTargets.createTargets completes ARScanScreen.tsx + ARScene.tsx
WHY THIS CRASHES arMounted becomes true on first focus. ViroARSceneNavigator renders immediately. The useEffect that calls createTargets depends on billboard from useBillboard — which is an async fetch. On a slow connection, ARScene is fully mounted and ViroARImageMarker tries to reference target_[id] BEFORE createTargets has run. Viro cannot find the target, logs a native error, and on some Android devices this causes a hard crash instead of a graceful miss.
// ARScanScreen.tsx — current (race condition) // arMounted → true immediately on focus // createTargets → runs only after billboard fetch resolves // Gap between these two = crash window // Fix: gate arMounted on BOTH focus AND target registration const [targetReady, setTargetReady] = useState(false); useEffect(() => { if (!billboard?.image_target_url) return; const targetName = `target_${billboard.id}`; ViroARTrackingTargets.createTargets({ [targetName]: { source: { uri: billboard.image_target_url }, orientation: 'Up', physicalWidth: billboard.physical_width || 1, }, }); setTargetReady(true); // AR can now mount safely }, [billboard]); // Only mount ViroARSceneNavigator after target is registered {arMounted && targetReady && ( <ViroARSceneNavigator ... /> )}

Warning arMounted latch never resets on back-navigation — second scan session broken ARScanScreen.tsx
SCENARIO User scans billboard A → goes back → opens billboard B. arMountedRef.current is still true from session A. The 500ms delay logic never fires the reset because the screen was fully unmounted (not just blurred). On remount, arMounted is already true from the useState initial render — but targetReady is false for the new billboard. The AR session starts with no registered target. Result: second scan never works.
// Fix — reset on unmount, not just on focus loss useEffect(() => { return () => { // Cleanup on screen unmount (back navigation) arMountedRef.current = false; setArMounted(false); setTargetReady(false); }; }, []);
